# Core Invariants

本文件每次会话都加载，任何场景上下文都不能覆盖它。它是 `01-agent-layer/AGENT_GUIDE.md` 的行为不变量摘要；若两者冲突，以 `01-agent-layer/AGENT_GUIDE.md` 为准并立即修正本文件。

1. **单一规范入口。** 所有适配层只转发到 `01-agent-layer/AGENT_GUIDE.md`，禁止形成第二套规则。
2. **文件是事实源。** 状态、决策、证据和交接必须落到事项文件；聊天记忆不是唯一凭据。
3. **先恢复再行动。** 开始前确认事项、目标、当前状态、下一步和有效边界。
4. **保留原有行为。** 新指令不自动废止旧验收标准；变化必须有明确记录。
5. **模式切换不是重置。** 切换 coding/review/sync 时保留事项、约束、风险和禁止动作。
6. **物理隔离。** 默认只写当前事项目录；跨事项修改必须说明原因并独立记录。
7. **最小加载但不丢行为。** 只读当前场景需要的内容；核心、状态、交接和路由必须加载。
8. **安全自主。** 可逆、低风险、范围内动作自主完成；破坏性、外部副作用、权限扩大和关键歧义先询问。
9. **过程可恢复。** 有意义步骤写 journal；暂停或交接前更新 STATUS 与 handoff。
10. **证据先于结论。** 未运行验证不得声称通过、完成或修复。
11. **保护共存改动。** 不覆盖他人的未提交工作，不把无关改动卷入提交。
12. **完成即同步。** 完成必须同时包含交付物、验证、状态、交接和 Git 检查点。
13. **压缩后重载。** 上下文压缩、跨 Agent 或跨会话后，从文件和 Git 重建事实。
14. **高风险动作需授权。** 发布、部署、发送、付费、删除、改写历史、推送共享分支均需用户明确要求。
15. **委派不等于验收。** DeepSeek 或其他执行 Agent 的完成声明必须由 Codex 检查变更并独立运行测试后才能接受。
16. **规则共享、事实隔离。** 所有工程共用唯一 `01-agent-layer`；工程的事项和状态只写各自工程目录，不跨工程共享。
17. **审查独立封存。** Codex 每轮审查必须写入 `reviews/<task-id>/round-<n>/`，不得覆盖、合并轮次或把完整报告塞回 STATUS。

出现“为了省时间先跳过记录/验证”的念头时，停下来：省下的是几秒，丢失的是下一次会话能够继续工作的能力。
